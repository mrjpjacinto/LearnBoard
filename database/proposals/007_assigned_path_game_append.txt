Assigned Learning Path games fix

The existing learnboard_save_path_games function rejects all changes when any individual or class assignment exists. The editor currently lets users add games, then reports that database refusal.

007_assigned_path_game_append.sql replaces that blanket rejection with append-only editing for assigned paths. Existing game links, link IDs, order, assignments, attempts, runtime, scores and files are unchanged. New games appear at the end for current students. Paths without assignments retain full rearrange/remove functionality. Authentication, active-school checks, tenant boundaries, the 200-game limit and stale-edit protection remain enforced inside the RPC.

The app disables removal and movement of existing assigned games and explains why. New unsaved additions can be rearranged or removed until saved.

This fix does not depend on proposals 005 or 006 and can be applied first. The SQL guard verifies the original reviewed function and refuses a different definition or an additional sequence guard. Do not rerun proposal 004.
